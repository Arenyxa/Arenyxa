# Arenyxa V9.1 Hybrid Flagship — Merge Report

## Authoritative baseline

`arenyxa_v9_0_no_scene_words` remains the authoritative interaction runtime. Its scroll timeline, camera easing, intro, Digital Earth, node interaction, text reveal and responsive choreography were not replaced by the Flagship scene manager.

## Donor modeling system

The Flagship Website was used as the modeling reference for:

- rounded/chamfered industrial housings;
- physically based black aluminum, satin metal, ceramic, PCB and glass surfaces;
- port banks, vents, LEDs and physical I/O detail;
- server-blade internal architecture;
- capture appliance composition;
- hardware-first Root crypto package;
- developer network-measurement instrument composition.

These concepts were adapted into the V9.0 inline Three.js builders so the first site's motion characteristics remain intact.

## Scene impact

1. Digital Earth — V9.0 Earth retained; PBR environment benefits surrounding physical models without replacing geography.
2. Data Spine — processor modules and nearby hardware now use rounded industrial shells and front-panel I/O.
3. Sensor Field — upgraded endpoint/switch/server primitives propagate into the scene.
4. Capture — NX-CAP appliance, server internals and scroll-driven shell reveal added.
5. Evidence — shared rounded/PBR primitives improve vault and artifact hardware.
6. Protocol — shared rounded/PBR plate and chassis treatment improves analyzer geometry.
7. MITM — upgraded endpoint/switch/server primitives improve path endpoints and gateway context.
8. Zero Trust — shared physical materials and hardware nodes improve trust architecture.
9. Root — crypto die/package changed to a layered carrier/package/die/traces structure.
10. Runtime — upgraded hardware modules propagate into the runtime system composition.
11. Traffic Forensics — packet blocks now use beveled product geometry.
12. Developer — rebuilt around a full Arenyxa measurement instrument with display, knobs, keys, ports, LEDs, vents and cables.
