Arenyxa V9.1 Hybrid Flagship
============================

This build combines the smooth V9.0 no-scene-words camera/scroll runtime with the industrial procedural modeling language of Arenyxa Flagship Website.

Preserved from V9.0
- Smooth 12-scene scroll/camera timeline
- Earth drag, inertia, auto-rotation and clickable node focus
- Visible continent/geography texture pipeline
- Repeatable text reveal
- Giant atmospheric scene words remain removed
- Existing intro, responsive choreography and reduced-motion behavior

Flagship modeling upgrades
- Rounded/chamfered product shells
- PMREM RoomEnvironment PBR reflections
- black aluminum / satin metal / polymer / ceramic / PCB material families
- modeled port banks, vents and status LEDs
- rebuilt endpoint, switch, server-rack and Data Spine processor modules
- detailed NX-CAP capture appliance
- scroll-driven server shell reveal exposing PCB/NIC/CPU/backplane
- refined Root crypto package
- full developer network-measurement instrument with display, knobs, soft keys, ports, vents and physical cables

Languages
English / 简体中文 / 繁體中文 / 日本語 / 한국어 / Deutsch / Français / Español

Run
  cd "<folder>"
  npm run start -- --port 3100

No npm install is required for the local server. Open http://localhost:3100/
Three.js ESM modules load from jsDelivr, as in the original V9.0 site.
