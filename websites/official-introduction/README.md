# Arenyxa Official Introduction

Official introduction and technical documentation portal for Arenyxa. The static site preserves its deep engineering chapters, including Network Capture, MITM Engine, Protocol Intelligence, Enterprise, Root Developer, runtime, resilience, CLI, quality and release engineering.

## Languages

简体中文, 繁體中文, English, 日本語, 한국어, Deutsch, Français, Español and Русский. The site detects browser language, supports manual switching, and stores the selected language in local storage.

## Production

- Official Introduction: https://arenyxa.github.io/
- Flagship Website: https://arenyxa.pages.dev/
- Source Repository: https://github.com/Arenyxa/Arenyxa

Open `index.html` directly or serve this folder from any static web server.
