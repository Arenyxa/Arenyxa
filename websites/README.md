# Arenyxa Websites

This directory archives the deployable source for the two public Arenyxa web properties.

- `flagship/` — Arenyxa v9.1 Hybrid Flagship Experience, deployed to [arenyxa.pages.dev](https://arenyxa.pages.dev/).
- `official-introduction/` — multilingual Official Introduction site, deployed to [arenyxa.github.io](https://arenyxa.github.io/).

Both copies are source archives. The Flagship site validates its static production root with `npm run build`; the Official Introduction is a dependency-free static site for GitHub Pages.
