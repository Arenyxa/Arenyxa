# Arenyxa v7.0 Protocol Intelligence, Deep Capture & Terminal Maturity Report

## Scope

This hardening cycle raises network-analysis maturity in four areas: protocol breadth, packet/capture depth, bounded large-capture processing, and first-class terminal diagnostics. The implementation deliberately avoids claiming literal support for every network protocol. Protocol ecosystems include proprietary, encrypted, undocumented, malformed, experimental, and future formats, so Arenyxa uses a two-layer model: a deterministic native core plus dynamic discovery from an optional external dissector runtime.

## 1. Protocol coverage architecture

### Native structured core

The dependency-free native decoder exposes **87 structured protocol families**. Coverage spans:

- Link and encapsulation: Ethernet, VLAN, MPLS, Loopback/NULL, PPP/PPPoE, Radiotap, IEEE 802.11, LLDP, EAPOL.
- Network and routing: IPv4, IPv6, ICMP/ICMPv6, IGMP, OSPF, VRRP, PIM, EIGRP, IP-in-IP, IPv6-in-IPv4.
- Transport and security: TCP, UDP, SCTP, DCCP, GRE, AH, ESP, TLS, QUIC, IKE, WireGuard.
- Naming/configuration: DNS, mDNS, LLMNR, NBNS, DHCP, DHCPv6, NTP.
- Web and interactive: HTTP/1 metadata, HTTP/2 preface, WebSocket handshake, SSE handshake, SSH, FTP, SMTP, POP3, IMAP, SIP, RTSP, SSDP, Syslog, SOCKS, RFB.
- Messaging/data services: MQTT, AMQP, Redis, Memcached, MySQL, PostgreSQL, MongoDB, LDAP, SMB, Kerberos, BGP, SNMP, RADIUS.
- Overlay/real-time/RPC: VXLAN, Geneve, GTP, L2TP, STUN, CoAP, RTP/RTCP, ONC RPC/NFS, TFTP, RIP.
- Industrial/OT: Modbus/TCP, BACnet/IP, OPC UA TCP, IEC 60870-5-104 framing, DNP3 framing, S7 communication metadata.

Native decoding is metadata-oriented. Sensitive plaintext values such as authentication secrets are not intentionally copied into diagnostic snapshots.

### Dynamic broad-coverage layer

When the optional external dissector runtime is available, Arenyxa queries its live protocol and field registries instead of maintaining a fake fixed list. The dynamic layer provides broad long-tail protocol trees, validated arbitrary field extraction, display filters, follow-stream, object export, capture formats/link types, merge/convert/reorder operations, and advanced statistics. This lets the installed runtime determine long-tail protocol breadth while Arenyxa preserves its own stable APIs and native fallback.

## 2. Deep capture improvements

- Native classic PCAP and PCAPNG streaming readers with bounded packet/block sizes and packet-count limits.
- Common link types include Ethernet, Raw IP, Linux cooked capture, Loopback/NULL, PPP, Radiotap, and IEEE 802.11.
- 802.11 protected payloads are marked encrypted rather than falsely decoded; unprotected LLC/SNAP data can descend into IPv4/IPv6.
- IPv6 extension-chain parsing is bounded; malformed/truncated frames stop safely with warnings.
- Tunnel/overlay descent supports GRE, IP-in-IP, IPv6-in-IPv4, VXLAN, Geneve, and common encapsulation paths.
- Native directional TCP state reports retransmission, out-of-order, zero-window, reset, and sequence gaps.
- New bounded TCP stream reassembly can recover application identification when headers/handshakes cross TCP segment boundaries.
- Reassembly budgets: 4,096 active directions, 64 KiB application probe prefix per direction, 128 KiB pending out-of-order data per direction, 64 pending segments, and a 64 MiB global retained-data ceiling.
- Reassembled raw payload is not emitted into diagnostics; metadata contains protocol identity, structured fields, byte counts, gap/order status, and bounded warnings.

## 3. Large-capture maturity

Packet summaries and NetworkEvent conversion have streaming iterator paths with limits up to one million packets. PCAP import persists events in bounded batches instead of first constructing an unbounded in-memory list. Native statistics use bounded high-cardinality maps for endpoints, conversations, flows, warnings, and time buckets and explicitly report cardinality truncation.

A synthetic native PCAP benchmark in the current Linux validation container processed 100,000 simple DNS packets in about 1.97 seconds (roughly 50.8k packets/s) without whole-file materialization. This is a narrow synthetic measurement, not a universal production throughput guarantee; real performance depends on protocol complexity, storage, external runtime use, hardware, and capture structure.

## 4. Packet analytics accuracy

Protocol statistics now prioritize the highest recognized application protocol instead of accidentally collapsing imported TLS/HTTP2/application traffic into TCP. Imported endpoint fields accept the capture pipeline's source/destination-address schema, including IPv6-safe endpoint formatting. Native-only mode retains protocol hierarchy, endpoints, conversations, expert/warning summaries, I/O buckets, packet lengths, flow graph, service statistics, and basic RTP/RTCP counts.

## 5. Developer Terminal network capability

The project-scoped terminal adds bounded, single-target network and packet analysis commands:

- `net-capabilities`, `net-resolve`, `net-reverse`, `net-dns`
- `net-tcp`, `net-tls`, `net-interfaces`, `net-sockets`
- `net-service`, `net-protocol`
- `packet-capabilities`, `packet-protocols`, `packet-fields`
- `packet-decode` for bounded native frame decoding from hex
- `packet-info`, `packet-summary`, `packet-frame`, `packet-stats` for offline capture analysis

These commands reuse the same validation, output-budget, project-scope, TLS-verification, and packet-analysis layers as the desktop application. They do not introduce a bulk scanner.

## 6. Safety and resource invariants

- Native frame limit: 16 MiB.
- PCAPNG block limit: 32 MiB.
- Native packet iterator limit: one million packets.
- Bounded layer count, VLAN/MPLS depth, IPv6 extension count, DNS compression recursion, text line size, stream state, and statistics cardinality.
- TLS network probes require certificate-chain verification and hostname verification.
- Encrypted or protected payloads are not presented as decrypted data.
- External field extraction validates requested fields against the runtime registry and applies row/field limits.

## Remaining boundaries

“Every network protocol” is not a finite truthful target. Arenyxa cannot decode encrypted application content without authorized keys/visibility, and undocumented proprietary formats may remain metadata-only or depend on the external runtime. Some uncommon PCAPNG block semantics may be safely skipped by the native reader. Full display-filter language evaluation and the broadest long-tail dissection remain external-runtime features. These boundaries are explicit rather than hidden behind inflated support claims.
