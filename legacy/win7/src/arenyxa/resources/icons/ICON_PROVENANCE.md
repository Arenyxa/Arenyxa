- Canonical application icon: `arenyxa.png` (1024 × 1024, RGBA).
- Windows multi-size icon: `arenyxa.ico` containing 16, 24, 32, 48, 64, 128, and 256 px entries.
- v8.2 refreshes the user-approved Arenyxa identity from the provided application artwork: a geometric `A` frame around a luminous core, graphite / electric-blue language on a dark rounded badge.

- Generated `arenyxa.png` SHA-256: `74f998e6f6130f5638252c323a2baf74c3d3fc42fa8cfa69c0e6692751855b81`.
- Generated `arenyxa.ico` SHA-256: `77c912a33d18df9ba686a8bdac93751b87244fd8ec7acac4cc1b51cba2f6ebe2`.
- The wordmark is intentionally excluded from the icon so the mark remains readable in the Windows title bar, taskbar, Explorer, installer, About page, and startup surfaces.
- The runtime PNG and Windows ICO are generated from the same canonical artwork so Desktop, taskbar, tray, About, PyInstaller, and Inno Setup use one identity.
- The 1024 px PNG is RGBA; outer canvas corners outside the rounded application badge are transparent.
- Product release identity is Arenyxa v8.2.0. Plugin/runtime compatibility remains `6.8.0` and is not changed by this visual refresh.
