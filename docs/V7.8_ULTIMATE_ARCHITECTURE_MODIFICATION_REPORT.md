# Arenyxa v7.8 Ultimate Architecture 修改报告

## 发布身份

- 产品：Arenyxa
- 公共版本：7.8
- 包版本：7.8.0（符合 v7.8.x 目标并保持既有兼容契约）
- 交付物：`Arenyxa_v7.8_Ultimate_Architecture_Final.zip`

## 完成的改造

### Navigation 与权限

- 新增独立的 Experience Mode、Runtime Mode、Account Role、Developer Authority、Active Root Session 模型。
- 新增声明式 Page Manifest、确定性 Resolver、Registry、Guard、Context Factory 和惰性 Page Factory。
- 个人 Advanced 用户不再看到 Enterprise；Desktop 不显示 Server Admin；Developer Experience 不再授予 Developer Authority。
- Root `SHOW_ALL` 只由有效的进程内 Root Session 触发，Root 状态未写入配置。
- MainWindow 路由和按钮可见性使用相同权限决策，deep-link 不能绕过导航隐藏。

### 页面生命周期与性能

- 移除启动阶段的全页面实例化路径，只创建首个页面并在访问时惰性构造其余页面。
- Preset 切换不销毁页面，使用 `NavigationDiff` 更新变化项。
- Preset 的持久化和 Diff 准备移出 Qt 主线程，并使用 generation 防止过期回调覆盖新状态。
- 新增 `preset_switch_latency_ms` 指标。
- Data 结果视图迁移到异步、稀疏、LRU 有界的 `QAbstractTableModel` 虚拟页模型。

### 启动与 Root UX

- 新增 `ArenyxaShellWindow` 及 Splash/Auth/Recovery/Main 四个内部页面。
- MainWindow 在 Root challenge 完成前不构造，构造时即为 Shell 子部件。
- Root Authority Challenge 展示设备、TPM、challenge fingerprint 和 verification state。
- Root 失败停留在认证页，可选择普通会话，不再强制退出。
- 中断恢复摘要在同一窗口显示，不再通过隐藏/显示 MainWindow 完成交接。

### 稳定性

- 新增 Runtime Supervisor，覆盖 UI、Async、Worker、Database、Capture heartbeat/probe。
- Event Loop block 超过 5 秒会记录全线程栈和有界诊断状态。
- SQLite 新增 WAL monitor、checkpoint、corruption snapshot 和脱敏慢查询日志。
- PostgreSQL 新增连接健康、指数退避重试和无敏感信息 transaction trace。
- 保留既有 crash marker、runtime recovery、Repair Center 和 shutdown coordinator。

### 协议能力

- TLS intelligence 新增 JA4，并把 JA4 接入 TLS session、packet forensics 和 evidence graph。
- Certificate graph 增加 subject/issuer/chain 关系。
- 新增有界 Protobuf、AMQP 和 Kafka 原生 decoder，并把 AMQP/Kafka 接入应用层分发。
- 保留并验证 HTTP、HTTP/2、HTTP/3、QUIC TLS 1.3、DNS/DoH/DoT/DoQ、WebSocket、gRPC 和 MQTT。

- 未删除既有功能、核心引擎或公开 API。
