## 需求归一化结论

1. Arenyxa 是本地优先、开源并采用确定性本地处理的软件；网络只在用户显式发起抓取、分析、连接或 Marketplace 操作时使用。
2. Task 是可编辑定义，Run 是不可改写的执行事实；结果、抓包会话、Revision、Workflow 与日志必须可追溯。
3. 主窗口固定为左侧导航、顶部工具栏、中央工作区、右侧上下文检查器和底部状态栏。主题只能替换语义 Token，不得改变信息架构。
4. 网络数据分 Browser Capture 与 System Packet Capture 两层：前者在受控浏览器内观察 HTTP(S) 语义，后者依赖 tshark/dumpcap/Npcap 且不得宣称解密 TLS 正文。
5. 大数据路径使用分页、流式写入、有界队列与批次提交；超载必须记录 Dropped，不得静默丢弃。
6. 所有阻塞 I/O、解析、导出、版本构建、网络检查和数据库探针不得运行在 GUI 事件线程。
7. Liquid Glass 是可降级材质层；Spring/Morph/Edge Flow/Live Motion 由统一编排器管理，按真实时间适配 60/90/120Hz，并保留 Reduce Motion 与实体回退。
8. 插件、终端、服务端与项目包均采用最小权限、显式授权、稳定错误码、秘密脱敏、路径边界和资源预算。

完整需求清单见 `SOFTWARE_REQUIREMENTS_SPECIFICATION.md`，模块树见 `FUNCTION_MODULE_TREE.md`，UI 树见 `UI_COMPONENT_TREE.md`，架构与数据流见 `ARCHITECTURE.md`。
