# Arenyxa v0.1

Arenyxa v0.1 is the first formal public release in the GitHub public version line.

The project went through a long internal engineering cycle before public release numbering was established. Historical identifiers such as v6.x, v7.x, v8.0, v8.1, v8.1.1, and v8.2.0 are retained as internal engineering milestones and validation provenance. They are not previous public semantic versions.

## Release identity

- Public display version: `v0.1`
- Package / distribution version: `0.1.0`
- Windows file version: `0.1.0.0`
- Internal engineering baseline: `v8.2.0`
- Runtime / plugin compatibility identity: `6.8.0`
- Release channel: `stable`

Database schema versions, workflow schemas, Enterprise protocol versions, plugin API versions, migration identifiers, permission IDs, event/protocol codes, and other machine compatibility contracts remain independent from the public product version.

## Highlights

Arenyxa v0.1 brings the current engineering baseline into a single public release line, including:

- Network capture and analysis
- Browser, HTTP, HAR, PCAP and packet workflows
- Proxy / MITM debugging for authorized environments
- Protocol intelligence, traffic forensics and replay
- Search, structured data, dataset revision and export
- Workflow automation, scheduling and visualization
- Local-first storage and diagnostics
- Repair Center and release provenance
- Enterprise identity, governance, Server / Worker and Fleet workflows
- Developer and Root authority security boundaries
- Semantic internationalization across the high-visibility desktop UI
- Modern Windows desktop lane plus the frozen Windows 7 compatibility lane

## Windows installer

Primary Windows x64 installer:

`Arenyxa_v0.1_Setup_x64.exe`

Verify the SHA-256 sidecar before installation.

The installer published in this release is built from the v0.1 source identity. Historical v8.x installers are not renamed or reused as v0.1 artifacts.

## Compatibility

Arenyxa v0.1 intentionally keeps the existing runtime/plugin compatibility identity `6.8.0`. Public version numbering and compatibility numbering are separate contracts.

See `VERSIONING.md` and `docs/release/COMPATIBILITY_MATRIX.json` for the complete model.

## Historical engineering snapshots

Older GitHub Release entries with v8.x tags are retained for engineering provenance. They represent internal development snapshots created before the public numbering policy was corrected and are not part of the v0.x public release sequence.
