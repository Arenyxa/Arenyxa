# First-run Welcome Center contract

The approved startup animation remains byte-frozen. After that animation, the first-run experience is shown **inside the same Arenyxa MainWindow**, avoiding a second-window handoff.

Phase 4–5 offers real Experience choices: Personal, Power User, Professional and Developer Profile. `Experience != Capability`: these options change presentation/default navigation only. Developer Profile is not Official Developer Access and does not bypass the Developer Mode agreement.

Enterprise & Operations and Server / Worker are visible only as disabled roadmap placeholders. Phase 4–5 does not create fake Enterprise accounts, Vault/RBAC, Coordinator, Server or a second Runtime.

Settings and Personalization remain separate. Settings contains operational/system/security configuration and a `使用模式` entry that can reopen this page. Theme presets, motion and UI scale remain in Personalization.
